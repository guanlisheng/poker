# 盲注时钟：让全场看到同一个比赛进度

比赛现场最怕的不是倒计时少了几秒，而是不同设备显示的时间不一致，导致主持人、选手和其他屏幕各说各话。

## 以级别结束时刻为基准

按照当前产品的设计，服务器维护比赛状态和当前级别的时间信息，终端根据目标时刻计算剩余时间。

这与只在浏览器里每秒减一的简单计时器不同：终端重新加载或重新取得比赛状态后，可以根据最新时间信息重新计算倒计时。

## 常见操作

- **暂停与继续**：暂停后冻结比赛进度，继续后从暂停时的剩余时间恢复。
- **手动跳级**：根据现场需要切换到上一级或下一级。
- **调整时长**：临时延长或缩短当前级别，不必重建整套盲注结构。
- **终端刷新**：重新取得比赛状态后校准显示。

## 网络恢复后如何处理？

终端需要重新连接并取得最新状态。断网期间，屏幕能否持续显示、显示到什么程度，以及恢复所需时间，取决于终端当前实现和网络环境。

建议在正式赛事前做一次断网恢复测试，不要只根据演示环境判断现场可靠性。

## 开赛前检查

1. 创建一场测试赛事。
2. 开始、暂停，再继续。
3. 调整当前级别时长。
4. 手动跳级，确认盲注数字变化。
5. 刷新终端，检查是否恢复到正确的比赛状态。
6. 在实际网络条件下测试重连。
