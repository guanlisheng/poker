# 赛事管理：先复用规则，再开始比赛

一场比赛可以只设置名称和盲注模板，也可以根据需要调整级别时长、休息、报名截止级别和奖励名额。

## 从空白到开赛

1. 选择系统提供的盲注模板，或选择俱乐部已保存的模板。
2. 填写赛事名称、赛事类型和相关设置。
3. 按实际需要设置报名截止级别、奖励名额等信息。
4. 在终端设备管理中，将显示设备分配给对应赛事。
5. 检查大屏信息，再开始比赛。

## 模板和赛事不是同一份配置

模板用于复用常见赛事规则。

根据当前产品设计，创建比赛时会复制模板中的级别结构。之后修改模板，不应覆盖已经开始比赛的级别表。

如果正在进行的比赛需要临时延长当前级别，应当直接操作比赛，而不是为了这一场比赛修改公共模板。

## 比赛进行中的常用操作

- 暂停与继续
- 上一级与下一级
- 当前级别时间调整
- 人数增加与减少
- 快捷计分
- 比赛复位

复位会影响当前比赛状态和相关统计，因此应先确认操作对象。实际复位行为以当前版本的界面提示为准。

## 赛事额度怎么算？

俱乐部的赛事额度是授权配额，不等同于可以创建的历史比赛总数。

按照当前产品规则，未开始、进行中和暂停的赛事占用额度；结束或删除后释放对应名额。具体状态和删除行为以当前版本为准。

## 建议的操作分工

- 所有者负责俱乐部默认配置和授权。
- 日常操作人员负责创建赛事、现场控制和终端分配。
- 只读成员负责查看赛事信息。
