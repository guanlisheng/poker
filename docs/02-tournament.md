创建一场比赛的流程可以很轻，也可以很细。轻到只填一个名字、选一个盲注模板就能开；细到每一级的时长、每一级的休息、报名截止级别、奖励名额都能单独设。

## 一场典型比赛的创建流程

1. **选一个盲注模板**。系统自带了标准赛、快速赛等模板，俱乐部也可以保存自己的常用结构。模板可以理解成"这场比赛每级多久、盲注怎么涨"的蓝图。
2. **填赛事信息**。比赛名称、赛事类型（多桌赛或单桌赛）、报名截止级别、奖励名额。
3. **分配终端**。把已经配好对的电视或投影指给这场比赛，它们就会显示这场比赛的实时信息。
4. **开始比赛**。点开始，倒计时启动，全场屏幕同步进入比赛状态。

## 模板和赛事是分开的

这一点值得单独说，因为它决定了你改模板时的安全感。

你保存的盲注模板是"蓝图"，每场比赛开始时会把蓝图**复制一份**成这场比赛自己的级别表。之后你再去改模板，已经开始的比赛完全不受影响。只有还在"未开始"状态的比赛，才会跟着模板更新。

这意味着：你今天临时想调整下一场比赛的节奏，可以直接改模板，不怕影响到正在进行的比赛；反过来，正在进行的比赛要临时延长时间，也是在比赛上改，不会污染模板。

## 控制台上每天在用的操作

- **暂停 / 继续**：一步到位，恢复时倒计时接着走。
- **上一级 / 下一级**：手动跳级，休息级会自动跳过。
- **时间 ±10 分钟**：临时延长或缩短当前级别。
- **人数 +1 / -1**：报名、淘汰、复活次数，都能单独记。
- **快捷计分**：常用报名金额提前存成按钮，点一下就把总码量加上去，不用手工敲数字。
- **复位**：一键回到未开始，清空人数和计分量，但保留比赛规则和奖励设置。

这些操作在网页控制台、手机小程序、电视遥控器上都能用，行为完全一致。
