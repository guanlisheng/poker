# 终端配置：让电视成为赛事大屏

大屏负责显示，管理端负责操作。你不一定需要为每一块屏幕购买相同的硬件。

## 浏览器终端

可以先在电视、电视盒子、电脑或平板的浏览器中打开：

[https://poker.nkucyd.cn/terminal](https://poker.nkucyd.cn/terminal)

如果页面提示等待配对，请根据终端页面实际显示的配对信息完成操作。

## 终端配对流程

1. 在显示设备打开终端页面。
2. 根据页面提示取得配对码。
3. 登录管理端，进入终端设备管理。
4. 输入配对码并为设备命名。
5. 将终端分配给需要显示的赛事。
6. 检查倒计时、盲注和赛事信息是否正常更新。

配对码的有效期、使用次数和凭证管理规则，以当前版本的实际实现为准。

## 三种显示方式

### Android TV 应用

适合拥有兼容 Android TV 或电视盒子、需要长期固定部署的场地。

安装方式、系统版本和兼容性应以实际发布的 APK 说明为准。

### AirPlay

适合已经有 iPhone、iPad 和兼容接收设备的临时场景。

屏幕镜像与应用原生的外部显示并不相同。使用前应检查电视上的比例、黑边、字体大小和显示内容，避免把管理界面一起投放出去。

### 浏览器

不需要为所有场地安装专用电视应用，但需要验证浏览器版本、全屏能力、休眠行为和网络恢复表现。

## 一台设备可以换绑赛事吗？

按照当前产品设计，已经配对的终端可以在管理端重新分配给其他赛事。是否需要重新配对，取决于设备凭证是否仍然有效。

## 开赛前的验收清单

- 终端可以打开并保持运行。
- 配对与赛事分配正常。
- 站在最远的牌桌位置仍能读清数字。
- 暂停、继续和跳级操作能正确同步。
- 语音音量符合现场环境。
- 设备休眠和网络中断后能按预期恢复。
