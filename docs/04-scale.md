# 从家庭局到固定场地

不要先购买设备，再考虑如何使用。先确认需要显示几场比赛、谁负责控制、现场网络如何部署。

## 家庭朋友局

**建议从一台屏幕开始。**

- 选择标准盲注模板。
- 使用电视、投影或已有浏览器设备。
- 根据现场习惯决定是否开启语音播报。
- 先完成一场完整测试，再决定是否需要自定义主题。

家庭局的核心是计时清晰、操作简单，不需要一开始就配置全部功能。

## 小型俱乐部

**优先统一常用配置。**

- 将常用盲注结构保存为模板。
- 统一筹码图例和默认主题。
- 为主屏、吧台屏等设备使用清晰的名称。
- 明确谁可以修改赛事、谁只负责查看。

如果需要同时运行多场赛事，应先确认当前授权是否支持对应的并行数量。

## 多屏场地

**先规划赛事与终端的对应关系。**

例如，主区域显示赛事 A，另一区域显示赛事 B。每台终端都应在管理端明确绑定目标赛事，避免工作人员临时操作时选错对象。

建议把设备命名、网络检查、语音音量和赛事模板纳入开赛前检查清单。

## 更大规模的赛事

如果涉及多个俱乐部、长期系列赛或更多终端，应重点确认：

- 并行赛事和设备配额
- 角色权限和跨俱乐部隔离
- 常用模板的维护流程
- 网络故障的恢复方案
- 授权、续期和设备撤销流程

## 先算清楚实际需求

| 需求 | 需要确认的问题 |
| --- | --- |
| 一块电视显示一场比赛 | 基础终端配对和赛事创建 |
| 多块电视显示同一场比赛 | 是否需要复制同一赛事到多块终端 |
| 不同区域显示不同赛事 | 是否支持所需的并行赛事数量 |
| 多人协同管理 | 角色权限是否符合现场分工 |
| 长期固定部署 | 浏览器或电视应用的稳定性和维护成本 |

当前试用额度为一台设备、一场占用额度的赛事。正式使用的设备和赛事上限以实际授权为准。
