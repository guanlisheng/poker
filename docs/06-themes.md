# 大屏主题：远距离看得清，也要符合场地风格

赛事大屏首先是一块信息屏。倒计时、盲注和级别信息必须清晰，视觉风格才有意义。

## 常见视觉方向

- **体育转播风**：深色背景、大号数字和醒目的状态色，适合较远距离观看。
- **会所风**：深绿、金色和克制的装饰，适合强调品牌感的场地。
- **编辑排版风**：清晰的分栏和留白，适合简洁、规整的视觉设计。
- **科技仪表风**：突出时间和级别变化，适合现代化的显示风格。

以上是设计方向示例，不代表当前版本一定包含这些名称或全部对应主题。

## 主题应显示哪些信息？

根据当前产品设计，主题可以使用的实时信息包括：

- 倒计时和当前级别
- 小盲、大盲、前注
- 下一级预告
- 参赛人数和剩余人数
- 奖励名额和赛事文案
- 俱乐部 Logo、赛事名称和当前时间

实际可用字段以当前主题编辑器和发布版本为准。

## 自定义主题

当前产品支持俱乐部管理员使用自定义 HTML 主题。

建议遵循以下原则：

1. 核心数字始终保持高对比度。
2. 不用装饰遮挡倒计时和盲注。
3. 背景图开启和关闭时都应保证信息区域完整。
4. 在电视实际尺寸上测试字体，而不是只看电脑预览。
5. 保存后确认终端是否正确更新。

自定义 HTML 具有一定风险。只应使用经过校验的模板，避免引入不必要的脚本或外部依赖。

## 系统主题与俱乐部主题

按照当前产品规则，系统主题由平台维护，俱乐部主题由对应俱乐部管理。具体可编辑权限以管理端为准。

## 如何选择？

家庭朋友局优先选择易读的默认主题；固定场地可以统一主题和 Logo；多屏环境则应先确保不同显示区域的信息层次一致。
