# 语音播报：让现场少一些重复提醒

“各位选手请注意，即将进入下一个级别。”

当选手无法一直盯着屏幕时，语音提醒可以帮助大家了解比赛进度。

## 两个播报时间点

**升盲前提醒**

在当前级别结束前提前播报，告知选手即将进入的级别及对应盲注。提前时间可以按产品提供的选项设置，当前默认值为 30 秒。

**升盲后播报**

在级别切换后播报当前级别，帮助现场确认比赛已经进入新的阶段。

两个选项可以独立设置。

## 声音选项

当前产品说明中列出了云健、云希、晓晓和晓伊等声音选项。实际可用的声音取决于当前语音引擎及服务配置。

选择声音时，建议在实际场地试听，避免在嘈杂环境中听不清数字。

## 三层配置

- **俱乐部默认**：设置俱乐部常用的语音行为。
- **单场比赛**：在产品支持的范围内覆盖俱乐部默认配置。
- **单台设备**：独立设置该设备的语音开关，适用于主屏出声、副屏静音等情况。

具体继承关系以当前版本的设置界面为准。

## 自定义播报文案

如果当前版本提供模板编辑，可以使用界面允许的占位符。不要自行添加未经支持的字段；保存前应检查预览或校验结果。

## 哪些时候应当静音？

- 现场已经通过扩音系统统一播报。
- 多块屏幕位于同一空间，避免重复播报。
- 比赛正在休息，现场希望保持安静。
- 某台终端只负责显示，不负责发声。

## 开赛前测试

1. 检查终端音量。
2. 测试升盲前提醒。
3. 测试升盲后播报。
4. 检查静音设备是否仍然显示正确的比赛信息。
5. 确认声音不会被电视系统或浏览器设置意外屏蔽。
