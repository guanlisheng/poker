# 西瓜大屏收费标准：免费试用 3 天，周授权 58 元起

准备在扑克俱乐部使用盲注计时和赛事大屏，除了功能是否适合现场，另一个实际问题就是：**西瓜大屏怎么收费？试用结束后怎么办？**

西瓜大屏面向线下扑克赛事场景，提供赛事管理、盲注计时、电视终端配对、多屏显示和语音播报等功能。

我们提供 3 天免费试用，并提供周、月、年三种授权时长。你可以先用自己的设备跑一场比赛，再决定是否长期使用。

## 一、免费试用：先跑通一场比赛

首次创建俱乐部即可免费试用 3 天，无需授权码。

试用规则可以简单理解为：

| 项目 | 免费试用额度 |
| --- | --- |
| 试用时长 | 3 天 |
| 同时进行的未结束赛事 | 最多 1 场 |
| 绑定的终端设备 | 1 台 |
| 功能 | 试用期开放全部功能 |

成员仍然按照所属角色的权限操作。

建议不要只浏览一下控制台，而是实际完成一次完整流程：

1. 创建俱乐部。
2. 创建一场测试赛事，设置盲注结构。
3. 将电视、电视盒子或其他支持的设备连接到终端。
4. 检查盲注、倒计时和赛事信息是否清晰。
5. 测试暂停、恢复、级别切换及其他需要的功能。

如果现场有多台电视，或者需要同时运行多场赛事，应在购买前确认正式授权对应的设备和赛事额度。

## 二、西瓜大屏收费价格

目前提供三种授权时长。

| 授权方案 | 价格 | 适合场景 |
| --- | ---: | --- |
| 周授权 | 58 元/周 | 短期赛事、临时活动 |
| 月授权 | 198 元/月 | 日常开赛、按月使用 |
| 年授权 | 1888 元/年 | 长期运营的俱乐部 |

以上为俱乐部授权价格。正式授权的赛事数量、设备数量等具体额度，需要在开通前联系确认。

### 周授权：适合短期办赛

如果你只是需要在某段时间内举办比赛，或者想先以较短周期投入使用，可以考虑周授权。

它适合短期使用需求，不必一开始就决定全年授权。

### 月授权：适合日常运营

如果俱乐部按月组织比赛，希望持续使用赛事管理和大屏计时功能，可以考虑月授权。

### 年授权：适合长期使用

如果西瓜大屏已经融入俱乐部的日常赛事流程，预计全年持续使用，可以考虑年授权。

选择年授权前，建议先利用试用期验证设备兼容性、操作流程和实际使用需求。

## 三、试用结束后，数据会不会消失？

按照当前产品规则，试用结束后需要兑换授权码才能继续使用。

到期后：

- 已有数据仍可查看。
- 俱乐部转为只读状态。
- 兑换授权码后恢复操作。

因此，试用结束不意味着已有数据会立即被删除。不过，如果你准备长期使用，仍建议提前安排授权续期，避免影响赛事管理工作。

## 四、如何购买或续期？

开通或续期的流程如下。

**第一步：联系获取授权码**

通过微信联系 `nkucyd`，注明俱乐部名称和需要的授权时长。

**第二步：确认价格与额度**

选择周、月或年授权，并在开通前确认正式授权所包含的赛事和设备额度。

**第三步：兑换授权码**

由俱乐部所有者进入控制台的「我的 / 俱乐部资料」，找到「延长使用时间」，输入授权码并完成兑换。

**第四步：核对有效期**

兑换完成后，检查新的授权有效期是否正确。

你可以先查看完整定价说明：

[查看西瓜大屏官方定价与授权说明](https://poker.nkucyd.cn/guide/?section=pricing)

## 五、提前续期，剩余时间会不会浪费？

不会。

按照当前产品规则：

- **尚未到期时续期：** 新增时长接在原有效期之后。
- **已经到期后续期：** 从兑换授权码时开始计算。

如果已经确定继续使用，可以提前办理续期，不必等到最后一天。

## 六、多个俱乐部如何计算授权？

不同俱乐部分别管理自己的有效期和授权额度。

如果需要增开俱乐部，应先确认是否符合创建条件，并按要求使用创建邀请码。

还需要注意，以下三种码的用途不同：

- **授权码：** 用于开通或续期。
- **加入邀请码：** 用于加入俱乐部。
- **创建邀请码：** 用于增开俱乐部。

不要将它们混用。如果不确定当前账号的权限或创建条件，可以在开通前联系确认。

## 七、应该选择哪种授权？

如果还不确定，可以按实际使用场景来选择：

- **只是想试试看：** 先使用 3 天免费试用。
- **只需要短期办赛：** 了解周授权。
- **每月都有比赛：** 考虑月授权。
- **准备长期运营：** 在试用验证后考虑年授权。
- **需要多台终端或同时运行多场赛事：** 购买前先确认正式授权额度。

不要仅根据价格选择方案。先确认产品适合你的场地和赛事流程，再决定使用周期，通常更稳妥。
