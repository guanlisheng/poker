## 从家庭局到固定场地

| 使用场景 | 优先考虑 |
| --- | --- |
| 家庭朋友局 | 一块电视或投影、标准盲注模板、基础语音设置 |
| 小型俱乐部 | 常用赛事模板、终端分配、筹码图例和日常操作 |
| 多屏场地 | 设备与赛事规划、角色权限、统一主题和同步 |
| 长期运营 | 授权配额、默认配置、设备维护和赛事工作流程 |

具体可用的并行赛事数量、终端数量和功能范围，以当前俱乐部授权为准。

[查看场地配置建议 →](./04-scale)

## 三种大屏接入方式

- **Android TV 应用**：适合具备兼容设备、希望固定部署的场地。
- **AirPlay**：适合已经有 Apple 设备和兼容接收设备、希望临时投屏的用户。
- **浏览器终端**：适合可以访问现代网页的电视、电视盒子、电脑和平板。

三种方式并不要求所有场地同时采用。先检查现有设备，再选择成本和维护方式合适的方案。

[查看大屏接入指南]({{ '/blog/poker-tournament-big-screen/' | relative_url }})

## 三天试用，先验证是否适合

当前试用配置为 1 台设备、1 场占用额度的赛事、3 天完整功能体验。

你可以用这段时间完成注册、终端配对、赛事创建和实际计时测试，再决定是否继续使用。

[查看试用规则 →](./05-trial)

## 四步开始一场赛事

### 1. 登录并进入俱乐部

登录或注册赛事控制台，创建自己的俱乐部，
或者使用所有者提供的加入邀请码。

[了解俱乐部与成员权限 →](./10-permissions)

### 2. 准备大屏终端

在安卓电视或电视盒子上安装赛事终端 APK，
打开应用并保持联网，等待屏幕显示配对二维码和六位配对码。

[查看终端安装与配对指南 →](./03-terminal)

### 3. 添加设备

进入「设备 / 终端设备」，扫描二维码或输入配对码。
绑定后，在创建赛事时选择对应终端。

注意：配对码有效期为 30 分钟，且只能使用一次。

### 4. 创建赛事并开始计时

创建赛事，选择盲注级别模板、显示主题和终端设备。
检查赛事信息与大屏画面后，进入控制台开始比赛。

[了解赛事创建与控制 →](./02-tournament)

---

手机或其他控制端负责赛事操作，终端负责大屏显示。
请先完成设备绑定，再将终端分配给需要显示的赛事。

[打开赛事控制台](https://poker.nkucyd.cn/)
