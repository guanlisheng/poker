## 它能解决什么问题？

### 盲注变化，一眼看清

大屏显示当前级别、倒计时、小盲、大盲、前注以及下一级预告。减少主持人反复报时和选手询问的次数。

[了解盲注时钟 →](./01-clock)

### 一场比赛，不必从头配置

通过盲注模板复用常见赛事结构。创建比赛后，当前比赛拥有自己的级别表，调整模板不会意外改变已经开始的赛事。

[了解赛事管理 →](./02-tournament)

### 电视负责显示，管理端负责操作

通过终端配对和赛事分配，将电视、投影、电视盒子或兼容浏览器设备接入比赛。

[了解终端配置 →](./03-terminal)

### 多块屏幕，围绕同一场比赛工作

在实际授权范围内，将终端分配到对应赛事。比赛状态变化后，相关终端获取最新信息。

[了解多屏同步 →](./09-realtime)

### 现场提醒，不必每次靠人喊

支持升盲前提醒和升盲后播报，并可按俱乐部、单场比赛和设备分别设置相关选项。

[了解语音播报 →](./07-voice)

## 从家庭局到固定场地

| 使用场景 | 优先考虑 |
| --- | --- |
| 家庭朋友局 | 一块电视或投影、标准盲注模板、基础语音设置 |
| 小型俱乐部 | 常用赛事模板、终端分配、筹码图例和日常操作 |
| 多屏场地 | 设备与赛事规划、角色权限、统一主题和同步 |
| 长期运营 | 授权配额、默认配置、设备维护和赛事工作流程 |

具体可用的并行赛事数量、终端数量和功能范围，以当前俱乐部授权为准。

[查看场地配置建议 →](./04-scale)

## 三种大屏接入方式

- **Android TV 应用**：适合具备兼容设备、希望固定部署的场地。
- **AirPlay**：适合已经有 Apple 设备和兼容接收设备、希望临时投屏的用户。
- **浏览器终端**：适合可以访问现代网页的电视、电视盒子、电脑和平板。

三种方式并不要求所有场地同时采用。先检查现有设备，再选择成本和维护方式合适的方案。
